# Simple React Accordion

This is a small React project that displays a clean FAQ-style accordion component.  
Each item can be expanded or collapsed by clicking on it.  
The component is built with basic React state (`useState`) and simple conditional rendering.

The project includes:

- A list of questions and answers
- Accordion items that open and close independently
- Minimal JSX structure and simple logic

This is a beginner-friendly example of handling UI state in React.
